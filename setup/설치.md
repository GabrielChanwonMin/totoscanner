# 설치 — 번호대로 따라가면 된다

준비물: GitHub 계정(있음), Supabase 계정(올팜 때 쓰던 것)

---

## A. GitHub 에 올리기

**A-1.** github.com 접속 → 로그인 → 우상단 **`+`** → **New repository**

**A-2.** 이렇게 채운다
- Repository name: `totoscanner`
- **Public** 선택 (무료 계정은 Pages 를 쓰려면 Public 이어야 한다)
- 아래 체크박스(README, .gitignore, license)는 **전부 비워둔다**
- **Create repository** 클릭

**A-3.** 다음 화면에 나오는 주소를 복사한다. 이렇게 생겼다
`https://github.com/내아이디/totoscanner.git`

**A-4.** 터미널을 열고 (Spotlight ⌘Space → "터미널") 아래를 붙여넣는다.
`내아이디` 부분만 네 것으로 바꿔라.

```bash
cd ~/Desktop/토토스캐너
git remote add origin https://github.com/내아이디/totoscanner.git
git branch -M main
git push -u origin main
```

**A-5.** 사용자 이름과 비밀번호를 묻는다.
비밀번호 자리에는 **계정 비밀번호가 아니라 토큰**을 넣어야 한다.
github.com → 우상단 프로필 → **Settings** → 맨 아래 **Developer settings**
→ **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
→ Note 아무거나, Expiration 은 **No expiration**, 권한은 **repo** 체크
→ **Generate token** → 나온 문자열을 복사해 비밀번호 자리에 붙여넣는다.
(이 문자열은 다시 못 보니 메모해둬라)

**A-6.** 올라갔으면 저장소 페이지 → **Settings** 탭 → 왼쪽 **Pages**
- Source: **Deploy from a branch**
- Branch: **main** / 폴더는 **/docs** 선택 → **Save**

**A-7.** 1~2분 뒤 같은 화면에 주소가 뜬다.
`https://내아이디.github.io/totoscanner/`
이게 **친구한테 줄 주소**다.

## B. Supabase — 회원 승인제 (이게 있어야 친구만 볼 수 있다)

이걸 건너뛰면 **주소를 아는 사람은 누구나 회차 데이터를 본다.**

**B-1.** supabase.com 로그인 → 프로젝트 선택 (없으면 New project)

**B-2.** 왼쪽 **SQL Editor** → **New query**
→ `setup/supabase.sql` 내용을 통째로 붙여넣고 **Run**
(맨 아래 주석 처리된 `update ...` 줄은 아직 실행하지 마라. B-6에서 쓴다)

**B-3.** 왼쪽 **Authentication** → **Sign In / Providers** → **Email**
→ **Confirm email** 을 **끈다** (아는 사람만 승인해서 들일 거라 메일 확인이 번거롭다)

**B-4.** 왼쪽 맨 아래 **Project Settings** → **API** 에서 세 개를 복사한다
- **Project URL** — `https://무언가.supabase.co`
- **anon public** 키 — 웹페이지에 들어간다
- **service_role** 키 — **수집기에만** 쓴다. 절대 저장소에 올리지 마라

**B-5.** 두 파일을 채운다

`docs/config.js` — 메모장/텍스트편집기로 열어서
```js
window.TS_CONFIG = {
  supabaseUrl: "https://무언가.supabase.co",
  supabaseKey: "여기에_anon_public_키"
};
```

`collector/secrets.json` — `collector/secrets.example.json` 을 복사해서 만든다
```json
{
  "supabaseUrl": "https://무언가.supabase.co",
  "serviceRoleKey": "여기에_service_role_키"
}
```
> `secrets.json` 은 `.gitignore` 에 있어 GitHub 에 안 올라간다. `config.js` 는 올라가는 게 맞다
> (anon 키는 원래 공개용이고, 접근 제어는 위에서 실행한 RLS 가 한다).

**B-6.** 바뀐 `config.js` 를 사이트에 올린다. **이걸 해야 로그인 화면이 뜬다.**
```bash
cd ~/Desktop/토토스캐너
git add -A && git commit -m "Supabase 연결" && git push
```
1~2분 기다린다.

**B-7.** 사이트를 열면 **로그인 화면**이 뜬다.
**가입 신청** 탭에서 네 이름·이메일·비밀번호(6자 이상)로 가입한다.
→ "승인 대기 중" 이 뜨면 정상이다.

**B-8.** Supabase **SQL Editor** 에서 아래를 실행해 **주인**이 된다.
이메일은 방금 가입할 때 쓴 주소로 바꿔라.

```sql
update public.profiles set approved = true, role = 'owner'
  where email = 'minchwen0205@gmail.com';
```

`Success. 1 rows` 이 나와야 한다. `0 rows` 면 이메일이 다르다는 뜻이니 확인해라.

**B-9.** 사이트를 새로고침한다.
들어가지면 성공이고, 상단 탭에 **회원 관리** 가 생긴다.

## C. 친구 들이기

1. 친구에게 **A-7 주소**를 준다
2. 친구가 **가입 신청** 탭에서 이름·이메일·비밀번호로 가입한다
3. 친구 화면엔 **"승인 대기 중"** 만 뜨고 아무 데이터도 안 보인다
4. 네가 사이트의 **회원 관리** 탭에서 그 사람을 **승인** 누른다
5. 친구가 새로고침하면 들어와진다

승인을 취소하면 다시 아무것도 못 본다. 언제든 되돌릴 수 있다.

> **인원 제한은 없다.** 몇 명이든 가입 신청할 수 있고, 네가 승인한 사람만 들어온다.
> 친구가 늘면 그냥 주소를 주고 `회원 관리` 에서 승인해주면 된다.

**모르는 사람이 주소를 알아내도** 로그인 화면만 보고, 가입해도 네가 승인하지 않으면
회차 데이터도 픽 기록도 못 본다.

---

## D. 매 회차

`토토스캐너 실행.command` 더블클릭 하나면 끝이다.
수집 → Supabase 업로드 → 사이트 열기까지 자동으로 한다. 붙여넣기 없다.

친구는 **주소만** 열면 최신 회차가 떠 있다. 파일을 다시 보낼 일도 없다.
