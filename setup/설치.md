# 설치 — 번호대로 따라가면 된다

준비물: GitHub 계정(있음), Supabase 계정(올팜 때 쓰던 것)

---

## A. GitHub 에 올리기

**A-1.** github.com 접속 → 로그인 → 우상단 **`+`** → **New repository**

**A-2.** 이렇게 채운다
- Repository name: `totoscanner`
- **Public** 선택 (무료 계정은 Pages 를 쓰려면 Public 이어야 한다)
- 아래 체크박스(README, .gitignore, license)는 **전부 비워둔다**
- **Create repository** 클릭

**A-3.** 다음 화면에 나오는 주소를 복사한다. 이렇게 생겼다
`https://github.com/내아이디/totoscanner.git`

**A-4.** 터미널을 열고 (Spotlight ⌘Space → "터미널") 아래를 붙여넣는다.
`내아이디` 부분만 네 것으로 바꿔라.

```bash
cd ~/Desktop/토토스캐너
git remote add origin https://github.com/내아이디/totoscanner.git
git branch -M main
git push -u origin main
```

**A-5.** 사용자 이름과 비밀번호를 묻는다.
비밀번호 자리에는 **계정 비밀번호가 아니라 토큰**을 넣어야 한다.
github.com → 우상단 프로필 → **Settings** → 맨 아래 **Developer settings**
→ **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
→ Note 아무거나, Expiration 은 **No expiration**, 권한은 **repo** 체크
→ **Generate token** → 나온 문자열을 복사해 비밀번호 자리에 붙여넣는다.
(이 문자열은 다시 못 보니 메모해둬라)

**A-6.** 올라갔으면 저장소 페이지 → **Settings** 탭 → 왼쪽 **Pages**
- Source: **Deploy from a branch**
- Branch: **main** / 폴더는 **/docs** 선택 → **Save**

**A-7.** 1~2분 뒤 같은 화면에 주소가 뜬다.
`https://내아이디.github.io/totoscanner/`
이게 **친구한테 줄 주소**다.

## B. Supabase 로 기록 공유 (선택)

이걸 건너뛰면 기록이 각자 브라우저에만 쌓인다. 계산·조합·방법론은 전부 똑같이 돌아간다.

**B-1.** supabase.com 로그인 → 프로젝트 선택 (없으면 New project)

**B-2.** 왼쪽 메뉴 **SQL Editor** → **New query**
→ `setup/supabase.sql` 파일 내용을 통째로 붙여넣고 **Run**

**B-3.** 왼쪽 메뉴 맨 아래 **Project Settings** → **API**
여기서 두 개를 복사한다
- **Project URL** (`https://무언가.supabase.co`)
- **anon public** 키 (긴 문자열)

**B-4.** `~/Desktop/토토스캐너/docs/config.js` 를 텍스트 편집기로 열어 채운다

```js
window.TS_CONFIG = {
  supabaseUrl: "https://무언가.supabase.co",
  supabaseKey: "여기에_anon_public_키"
};
```

**B-5.** 터미널에서

```bash
cd ~/Desktop/토토스캐너
git add -A && git commit -m "Supabase 연결" && git push
```

**B-6.** 사이트를 열어 우상단 `데이터` 옆과 기록 탭 제목을 봐라.
**공유 저장 (Supabase)** 라고 뜨면 성공이다.

## C. 매 회차

`토토스캐너 실행.command` 더블클릭 하나면 끝이다.
수집 → 커밋 → 푸시 → 사이트 열기까지 자동으로 한다. 붙여넣기 없다.

친구는 **A-7 주소만** 열면 된다. 파일을 다시 보낼 일도 없다.
